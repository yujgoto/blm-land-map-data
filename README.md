# blm-land-map-data

Vector tiles (PMTiles) of US public land by managing agency, built from the BLM National Surface Management Agency dataset (public domain).

Download the latest: `https://github.com/yujgoto/blm-land-map-data/releases/latest/download/sma.pmtiles`

Layer `sma`, properties `agency`, `unit`, `st`; zoom 4–12. Private/unknown land excluded. Coverage: contiguous US and Alaska (the source dataset does not include Hawaii or territories).

**Not legal advice.** Public land is not automatically open to shooting or camping; check local BLM field office orders.
